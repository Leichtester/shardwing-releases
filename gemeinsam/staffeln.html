Staffeln, Slots und Schlüssel ​

Auf einem öffentlichen Shardwing-Server darf nicht jeder einfach Missionen ablegen, sonst ist er schnell voll. Deshalb bekommt jede Staffel vom Betreiber ein kleines Kontingent: Slots.

Kurz gesagt

  • Slot = eine Mission, die gerade auf dem Server liegt. Eine Staffel mit 2 Slots kann 2 Missionen gleichzeitig dort haben.
  • Wird eine Mission gelöscht oder läuft ab, ist ihr Slot sofort wieder frei.
  • Jede Staffel bekommt zwei Dinge: einen Schlüssel zum Hochladen und einen Staffel-Link zur Übersicht.
Was ist das?Wer bekommt es?Was kann man damit?
Schlüsselkurzer Code wie K4P9-X2T7-M8QWalle Mission Designer der StaffelMissionen über Teilen auf den Server legen

Welche Rolle bist du?

  • Ich baue Missionen und will eine hochladen
  • Ich leite die Staffel und habe den Staffel-Link
  • Ich betreibe den Server

Mission hochladen ​

Du brauchst nur den Schlüssel deiner Staffel. Den bekommst du von deiner Staffelführung, meist im Discord.

  1. Mission in Shardwing öffnen, wie immer.
  2. Oben auf Teilen klicken.
  3. Beim ersten Mal den Staffel-Schlüssel eintippen oder einfügen. Groß- und Kleinschreibung und die Striche sind egal. Shardwing zeigt sofort, zu welcher Staffel er gehört und wie viele Slots frei sind.
  4. Auf den Server legen klicken. Fertig: Die Mission ist oben und du bist ihr Designer.

Ab dem zweiten Mal ist es noch kürzer: Shardwing hat sich den Schlüssel gemerkt. Also Teilen → Auf den Server legen.

Im Teilen-Fenster siehst du die Slots als kleine Kästchen: gefüllt = belegt, leer = frei.

„Alle Slots sind belegt“

Dann liegen schon so viele Missionen eurer Staffel auf dem Server, wie ihr haben dürft. Eine alte muss weg:

  • Bist du Designer der alten Mission: öffnen, Übersicht → Paket → Server → Vom Server löschen …
  • Sonst die Staffelführung fragen. Sie kann im Staffel-Panel jede Mission der Staffel löschen.

Anderer Schlüssel: Bist du in zwei Staffeln oder hat deine Staffel einen neuen Schlüssel bekommen, klick im Teilen-Fenster auf Anderer Schlüssel und gib den neuen ein.

Desktop-App: genauso. Beim ersten Mal steht im Teilen-Fenster zusätzlich das Feld Server, z. B. https://app.shardwing.de.

Staffel-Panel ​

Für die Staffelführung. Den Staffel-Link bekommst du vom Betreiber. Einmal öffnen genügt, danach steht Staffel-Panel im Shardwing-Menü. In der Desktop-App öffnest du den Link über Link öffnen (⌘L / Strg+L).

Den Staffel-Link nicht weitergeben

Wer ihn hat, kommt als Designer in alle Missionen eurer Staffel. Deine Leute brauchen nur den Schlüssel.

Das Panel zeigt:

  • Slots: wie viele belegt sind, wie viele frei. Dazu, falls der Betreiber es eingestellt hat, Speicher und „gültig bis“.
  • Schlüssel zum Hochladen:
    • Für Discord kopieren – Schlüssel mit einer Zwei-Zeilen-Anleitung, fertig zum Einfügen.
    • Nur den Schlüssel kopieren
    • Neuen Schlüssel ausstellen – wenn er zu weit herumgegangen ist. Der alte gilt dann sofort nicht mehr; Missionen auf dem Server bleiben, nur Hochladen geht dann nur noch mit dem neuen.
  • Eure Missionen:
    • Öffnen – du planst als Designer mit.
    • Designer-Link – kopieren, z. B. für einen zweiten Designer.
    • Löschen – macht einen Slot frei. Planung, Plätze und Kneeboards sind dann weg. Die geplante .miz vorher speichern: Öffnen → Übersicht → Paket → Server → Aktuelle .miz.
    • Mission hochladen … – eine .miz direkt hochladen, ohne sie vorher zu öffnen. Das ist dasselbe wie Teilen.

Wer das Panel einmal geöffnet hat, muss den Schlüssel im Teilen-Fenster nicht mehr eintippen. Shardwing nimmt ihn aus dem Panel.

Für den Betreiber ​

In der Server-Verwaltung (https://dein-server/#/admin, Master-Schlüssel) gibt es oben den Bereich Staffeln.

  1. + Neue Staffel: Name (z. B. JG 71 Virtual oder Tester Max), Slots (Standard 2), optional Speicher in MB und Gültig bis. Leer heißt: keine Grenze.
  2. Staffel anlegen. Shardwing zeigt Staffel-Link und Schlüssel.
  3. Nachricht kopieren und der Staffelführung schicken, am besten als Direktnachricht. Die Nachricht enthält beide Teile und erklärt, was wohin gehört.

In der Liste pro Staffel:

KnopfWas passiert
NachrichtStaffel-Link, Schlüssel und Anleitung kopieren (für die Staffelführung)
Schlüsselnur Schlüssel und Anleitung kopieren (für Mitglieder)
Panel-Linknur den Staffel-Link kopieren
ÄndernName, Slots, Speicher, Gültig bis. Dort auch Neuer Panel-Link und Neuer Schlüssel, falls etwas in falsche Hände geraten ist.
SperrenKeine neuen Missionen mehr, und in der Testphase öffnet der Schlüssel die App nicht mehr. Die Missionen auf dem Server bleiben und laufen normal weiter. Entsperren hebt das auf.
LöschenStaffel-Link und Schlüssel gelten nicht mehr. Die Missionen der Staffel bleiben und gehören ab dann dir.
  • Tester: eine normale Staffel, z. B. mit 1 Slot und einem Datum bei „Gültig bis“. Nach dem Datum kann sie nicht mehr hochladen, ihre Mission läuft normal ab.
  • Nur App-Zugang: Knopf + Nur App-Zugang legt einen Zugang mit 0 Slots an, z. B. für einen Tester oder Piloten, der nur planen soll. Der Schlüssel öffnet die App im Browser und am Desktop, hochladen kann er damit nichts. Nachricht kopiert Schlüssel, Browser-Link und Download der Desktop-App.
  • Testphase: Auf einem Server mit Master-Schlüssel öffnet sich die Web-App nur mit Staffel-Schlüssel, Staffel-Link, Missionslink oder Master-Schlüssel, die Desktop-App einmalig mit einem Schlüssel (siehe Installieren). Der Name der Staffel steht dann oben rechts als Beta · für … und klein auf jedem Kneeboard. Gesperrt, abgelaufen, gelöscht oder Neuer Schlüssel: Für diesen Schlüssel ist die App wieder zu. Die kopierten Nachrichten enthalten den Zugang schon. Mit SHARDWING_APP_OPEN=1 ist die App wieder für alle offen.
  • Missionsliste: In der Spalte Staffel steht, wer eine Mission hochgeladen hat. Betreiber heißt: mit dem Master-Schlüssel oder von einer gelöschten Staffel.
  • Master-Schlüssel: Du selbst lädst wie bisher ohne Grenze hoch. Im Teilen-Fenster: Ich betreibe den Server (Master-Schlüssel).
  • Server-Grenze: Mit der Umgebungsvariable SHARDWING_MAX_MISSIONS nimmt der Server keine Staffel-Missionen mehr an, sobald so viele Missionen insgesamt auf ihm liegen.
  • Notfall: npm run admin -w @shardwing/server auf dem Server listet alle Staffeln mit Staffel-Link und Schlüssel, dazu alle Missionen mit Designer-Link.

Auf einem Server ohne Master-Schlüssel (z. B. lokal) braucht niemand einen Schlüssel. Das Teilen-Fenster fragt dann auch nicht danach.
