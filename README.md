## In drei Schritten

1. **Öffnen** – `.miz` ins Fenster ziehen.
2. **Planen** – Threats freigeben, für jeden Flight *Neu aus Route*, Joker und Bingo eintragen.
3. **Speichern** – Cartridges und Kneeboards stecken in der Mission. In DCS laden, fliegen.

Schritt für Schritt: [Die erste Mission in 5 Minuten](https://leichtester.github.io/shardwing-releases/start/erste-mission)

## Installation

| System | Datei |
|---|---|
| Windows 10/11 (x64) | `Shardwing_<version>_x64-setup.exe` |
| macOS 12+ (Apple Silicon) | `Shardwing_<version>_aarch64.dmg` |

Beides liegt beim [neuesten Release](https://github.com/Leichtester/shardwing-releases/releases/latest).

> [!NOTE]
> Die Installer sind noch nicht code-signiert, beim ersten Start warnt das System deshalb einmal:
> - **Windows:** Bei SmartScreen auf „Weitere Informationen“ → „Trotzdem ausführen“
> - **macOS:** Rechtsklick auf die App → „Öffnen“

## Updates

Shardwing sucht selbst nach neuen Versionen und bietet sie unten rechts an. Installiert wird erst nach deinem Klick; jedes Update ist signiert und wird vor der Installation geprüft.

## Nutzung

Shardwing ist kostenlos und darf von jedem für eigene Missionen genutzt werden – privat und in eurer Staffel. Es wird ohne Gewähr bereitgestellt. Teilt am besten den Link zu dieser Seite statt der Installer – dann bekommen alle die Updates. Die Lizenzen der enthaltenen Bibliotheken, Karten und Skripte stehen in der App unter *Menü → Lizenzen*.
